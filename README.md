# Hours Ledger

An independent, on-device record of the hours you work. Records stay on the device; nothing is sent anywhere.

This repository holds the installable web version (version 1.6), served by GitHub Pages.

## Install on an iPhone

1. Open the site in Safari.
2. Tap Share, then Add to Home Screen, then Add.
3. Open Hours Ledger from the Home Screen and record there.
